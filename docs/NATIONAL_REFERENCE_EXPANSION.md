# Additional national institutional references

The optional institution configuration accepts `heida`, `level1_hospitals` and `level2_hospitals` in addition to the existing `hospitals` (Level 3), `unifast`, `beis`, `official_records`, and `verified_links` keys. All paths must be absolute. The three new reference files are supplied locally; they are not built into the wheel or added to the bundled manifest. No network access occurs during classification.

## CHED HEIDA

CSV header: `source_id,name,hei_type,ownership,address,source_url,as_of`. Source: https://heida.ched.gov.ph/hei-directory . The recovered November 4, 2026 snapshot has 2,424 eligible entries (664 public and 1,760 private), from a 2,745-row directory. The 321 review-only entries are retained separately, not loaded. Preserve string IDs including leading zeros and campus suffixes. Only explicit reviewed HEI types and unique non-placeholder codes are accepted. No municipality is inferred from an address. HEI codes identify an institution, not independently verified canonical sites; even an exact HEI code alone cannot promote ownership. Independently verified canonical links remain eligible under existing guards. Overlapping names from different sources are reviewed, not treated as identical sites. Redistribution permission is not established; use the local snapshot and respect source terms.

## PhilHealth Levels 1, 2 and 3

Use the September 30, 2026 accredited hospital list: https://www.philhealth.gov.ph/partners/providers/facilities/accredited/HOSP_093026.pdf . Official totals: Level 1, 781 (326 public, 455 private); Level 2, 432 (79 public, 353 private); Level 3, 125 (63 public, 62 private). All three levels use the existing hospital CSV schema, and are configured as separate files. `hospital_rows(..., level=1)` or `hospital_rows(..., level=2)` builds a typed reference from an official transcription. `level3_hospital_rows` and the existing Level 3 CLI remain unchanged. Infirmaries and dispensaries are excluded. Publication row IDs do not identify a site independently. Retain source URL, snapshot date, row identifier and explicit G/P sector. Never infer ownership or municipality from names. See https://www.philhealth.gov.ph/partners/providers/facilities/status.php for source totals.

The supplied external configuration installer checks the additional files, preserves bundled reference bytes, refuses to overwrite existing files and validates reference loading. Set `PLACETYPE_PH_INSTITUTION_REFERENCES` to the resulting configuration to opt in. The Express cache already fingerprints all configured references. These data sources expand coverage; they do not guarantee a resolved I-O code for every institution.
